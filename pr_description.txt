💡 **What:** Replaced the N+1 `is_installed` thread pool dispatches in `AppImageSearch.search` with a single batch disk read.
🎯 **Why:** The previous code spawned a separate thread pool task for every matched item which then globbed the `~/Applications` directory repeatedly. This was highly inefficient for larger searches. Now, the disk is hit once to get all installed files, and the installation check occurs synchronously in memory.
📊 **Measured Improvement:** In a benchmark with 100 installed mock AppImages and 500 search results evaluated 10 times, the execution time decreased from ~5.08s to ~0.05s (approx. 100x improvement).
